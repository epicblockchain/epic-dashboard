# Agent Instructions

## Commit messages

Use [Conventional Commits](https://www.conventionalcommits.org/) for every commit.

Format:

```text
<type>[optional scope]: <description>
```

Use a standard type such as `feat`, `fix`, `docs`, `refactor`, `test`, `build`, `ci`, `chore`, or `revert`. Keep the description concise, imperative, and lowercase without a trailing period.

Examples:

```text
feat(table): add perpetual tune grouping
fix(settings): persist column preferences reliably
docs: clarify release instructions
```

Mark breaking changes with `!` after the type or scope, or include a `BREAKING CHANGE:` footer.
